The signed-in user block at the right end of the topbar.

```jsx
<UserMenu name="Carla Mendoza" nickname="@carlam" initials="CM" />
```

The avatar stays on the left; the name and nickname are right-aligned within their column. The second line is the nickname taken from the Usuarios record — never the job title. It carries no chevron: the block is an identity display, not a dropdown trigger.
